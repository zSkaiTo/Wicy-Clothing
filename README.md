# Wicy Store

**Wicy Clothes** — a clean, modern storefront built for streetwear and everyday apparel.

This is a static clothing website with a strong brand feel from the first screen: a bold hero, product collections, promos, customer reviews, and newsletter signup. Everything is laid out the way shoppers expect on a real fashion site — clear navigation, big product visuals, and sections that build trust before someone buys.

## What you get

- **Hero** that sells the brand — split layout, hoodie showcase, and smooth motion that feels premium, not gimmicky  
- **Collections** for hoodies, sweatpants, and t-shirts with an easy category switch  
- **Promo banner** and **“what makes us different”** blocks so the store feels complete, not like a single landing strip  
- **Testimonials** and marketplace mentions so it reads like a store people already shop on  
- **Newsletter & discount** touchpoints that match how clothing brands convert visitors  

## Why it works for clothing

The design uses a neutral, high-end palette, strong typography (Inter + Plus Jakarta Sans), and spacing that lets product photos breathe. Cards, tabs, and the footer are polished and consistent — it doesn’t look like a generic template; it looks **built for apparel**.

Built with **HTML**, **CSS**, and **JavaScript** only — no framework, fast to load, easy to host anywhere.

## Run it

Open `index.html` in your browser, or use any simple local server (e.g. Live Server in VS Code) so images and fonts load cleanly.
